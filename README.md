# A20e Kernel – LineageOS

Custom kernel for **LineageOS** on the **Samsung Galaxy A20e**.

## Device

* **Device:** Samsung Galaxy A20e
* **Model:** SM-A202F
* **SoC:** Samsung Exynos 7884
* **Architecture:** ARM64
* **ROM:** LineageOS

## Kernel Package

The release is provided as an AnyKernel-style flashable ZIP.

**Package:** `A20e_Kernel_LineageOS.zip`

The package contains the kernel image and the required flashing components.

## Installation

> **Warning:** Flashing a custom kernel is performed at your own risk. Make sure you have a working recovery and a backup before proceeding.

1. Boot into a compatible custom recovery.
2. Create a backup of your current boot/kernel environment.
3. Flash the kernel ZIP.
4. Reboot the device.
5. Allow the device time to complete the first boot.

If the device fails to boot, restore your previous working boot image or backup.

## Compatibility

This kernel is developed for the Samsung Galaxy A20e **SM-A202F** running LineageOS.

Compatibility with other Galaxy A20e variants or other ROMs is not guaranteed.
